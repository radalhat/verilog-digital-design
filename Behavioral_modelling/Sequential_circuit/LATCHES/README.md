# Latches (Behavioral Modeling)

## Overview

This folder contains the behavioral implementation of basic latches in Verilog.

The designs use behavioral modeling to describe how latches store data based on their input signals. I created these projects to understand the operation of latches and strengthen my understanding of sequential logic in Verilog.

## Latches

The following latch designs are included:

- D Latch
- SR Latch

## Design

The latches are implemented using behavioral modeling with `always` blocks.

Each design is verified using a testbench that applies different input combinations to ensure the latch behaves according to its truth table.

## Summary

Working on these designs helped me understand how latches store data and how they differ from clocked sequential circuits such as flip-flops.
